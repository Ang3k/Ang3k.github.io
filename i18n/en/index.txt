Project summary

@@ 62ec7ea52f
I built an ensemble to classify dengue and chikungunya notifications using public data from SINAN, Brazil's notifiable diseases system, combining 107 features with the predictions of MLP, XGBoost and LightGBM models. The pipeline processed about 11.4 million raw records and, in the dengue test with 940,304 notifications from 2021, it found 87.3% of the confirmed cases. I then turned the model into an application with React and FastAPI.
